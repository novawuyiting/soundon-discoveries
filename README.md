## Measurement

Record baseline before sharing the page:

- Spotify playlist followers
- Daily streams for tracks in the playlist
- Stream source breakdown
- Streams from playlist source, if visible
- Target artist daily streams

The site logs outbound Spotify clicks into `window.dataLayer` and browser `localStorage` under `spotify_click_events`. For a hosted version, connect Google Tag Manager, GA4, Plausible, or Cloudflare Web Analytics and use the event name:

`spotify_playlist_click`

## First 14-Day Test

Day 0: capture baseline Spotify metrics.

Days 1-3: publish the page and submit it to Google Search Console.

Days 4-7: share the page in low-risk places where the phrase fits naturally, such as AI builder communities, coding newsletters, personal social posts, and short-form captions.

Days 8-14: compare Spotify stream lift and page clicks against the baseline.

Success threshold for the first test:

- 100+ landing page visits, or
- 20+ outbound Spotify clicks, or
- visible daily stream lift on playlist tracks versus the pre-test baseline.

## Next Iteration

If the page gets clicks but not streams, improve playlist ordering and first 10 tracks.

If the page gets impressions but few clicks, rewrite the title/meta description.

If the page gets no impressions, create two support posts targeting `AI coding music` and `Cursor coding playlist`.
